## 3. Práctica

**Ejercicio realizado:**

Desarrollo de una función llamada `contarPositivos()` para recorrer un array, identificar números positivos, negativos y ceros, y contar la cantidad de números positivos.

Array utilizado:

```javascript
let numeros = [4, -2, 7, -5, 0, -8, 3];
```

**Mi razonamiento:**

Comencé utilizando un ciclo `for` para recorrer todos los elementos del array.

Después utilicé una variable `contador` para registrar cuántos números cumplían la condición de ser mayores que cero.

Durante el ejercicio tuve dificultades para incorporar correctamente `else if` sin alterar la estructura original de las condiciones.

Después de revisar la sintaxis, comprendí que debía utilizar una condición dentro de `else if` y conservar el `else` para identificar los números que no cumplían las condiciones anteriores.

Finalmente, utilicé `return` para devolver la cantidad total de números positivos.

**Resultado obtenido:**

Conseguí completar el ejercicio y comprender mejor cómo combinar ciclos, contadores y estructuras condicionales para clasificar información.

## 4. Errores y correcciones

**Error:**

Dificultad para incorporar correctamente `else if` en la estructura condicional.

**Causa:**

Intenté colocar una instrucción `console.log()` directamente dentro de los paréntesis de `else if`, en lugar de escribir una condición que devolviera verdadero o falso.

**Solución y aprendizaje:**

Comprendí que `else if` necesita una condición entre paréntesis y que su bloque de instrucciones debe ir entre llaves.

También reforcé la importancia de mantener el orden de las condiciones para evitar clasificaciones incorrectas.
