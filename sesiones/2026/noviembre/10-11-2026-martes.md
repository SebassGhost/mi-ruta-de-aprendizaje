Se logró:

## 4. Errores encontrados y correcciones

**Error 1 — Confusión entre lista y elemento**

Se intentó comparar la lista completa (`numeros`) con un número, en lugar de utilizar el elemento actual (`numero`).

Corrección: utilizar la variable que representa cada elemento dentro del ciclo.

**Error 2 — Sumar una lista en lugar de un número**

Se escribió:

```python
suma = suma + ventas
```

Esto produjo un `TypeError` porque se intentó sumar un entero con una lista.

Corrección:

```python
suma = suma + venta
```

**Error 3 — Ubicación del acumulador**

La suma estaba dentro de una condición que impedía acumular todas las ventas.

Corrección: colocar el acumulador dentro del `for`, pero fuera de los bloques condicionales.

**Error 4 — Actualización del valor máximo**

Inicialmente se aumentaba `ventaAlta` en uno, en lugar de guardar el valor de la venta encontrada.

Corrección:

```python
ventaAlta = venta
```

También se aprendió a inicializar el valor máximo utilizando:

```python
ventaAlta = ventas[0]
```
